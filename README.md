# Parser X

面向 AstrBot 的国内平台作品链接解析插件。发送作品链接或分享文案，获取原始媒体及统一样式的图文、评论卡片。

- **AstrBot：`>=4.26.0,<5`**；消息适配器仅支持 **aiocqhttp / OneBot v11**，可用于群聊和私聊。
- 卡片使用插件内的 **Playwright Chromium** 本地截图，不依赖远程截图服务。
- 当前代码注册 14 个平台解析器。平台可访问性、账号权限与风控会影响实际结果，注册支持不等于所有链接和 QQ 投递形式均已验收。

## 支持范围

| 平台 | 主要内容与边界 |
| --- | --- |
| B站 | 视频、分 P、动态、热门评论；视频动态复用视频解析链 |
| 抖音 | 视频、图文、图集、热门评论 |
| 快手 | 视频、图片及可识别混合媒体、视频评论 |
| 微博 | 文字、图片、视频与混合媒体、热门评论 |
| 小红书 | 视频与图文笔记、满足登录与请求条件时的评论 |
| 小黑盒 | 普通帖子图文、可识别视频、热门评论；文章按平台标记判定，不按字数和图片数量猜测 |
| AcFun | 视频、热门评论 |
| 贴吧 | 首楼图文/可识别原生视频、可获取的公开网页根回复；不含楼中楼 |
| 微信公众号 | 公开文章、纯图集，保留正文图片顺序；不执行网页 JavaScript，不提取文章内嵌音视频 |
| 网易云音乐 | 单曲官方音频，以文件附件发送，不附封面卡或评论卡；部分歌曲只能试听或不可用 |
| NGA | 公开主题首帖图文、第一页根回复；不处理私帖或主题翻页 |
| 知乎 | 回答、想法、视频及公开专栏等已识别内容；受登录、权限及风控限制 |
| 酷安 | 公开 feed/picture、长文图文顺序；请保留原分享链接的 `shareKey` / `s` 参数，裸链接不保证可取正文；不提供评论 |
| 微信视频号 | 公开分享接口优先；必要时可选使用元宝登录态辅助解析 |

不处理直播。已识别的主页、搜索等非作品链接，以及不支持的卡片消息会静默跳过。短链接可能需要先请求跳转才能判断内容类型。

### 投递行为

- 图文使用统一深色卡片；评论支持作者/置顶徽章、楼中楼、平台表情与配图，实际可用字段依平台而异。
- 视频作品以视频和可用评论卡为主，不额外发送独立正文卡或简介文本；微博混合图文视频保留原媒体顺序。
- 网易云音乐只发送音频文件，不是 QQ 语音。使用官方接口实际返回的音源，不解锁付费或受限歌曲，不寻找替代音源。
- 多个产物通常通过合并转发交付。实况图不保证还原手机相册的原生 Live Photo。
- **单条下载资源上限为 100 MiB（104,857,600 字节）**。音视频分轨下载分别检查各轨；合并后的成品允许超过 100 MiB，不因合并总大小而额外降低清晰度或拒绝发送。这不是最终 QQ 消息附件大小承诺，协议端仍可能有自己的限制。

## 安装

在 **AstrBot WebUI → 插件管理** 使用仓库地址安装：

```text
https://github.com/Menkelo/astrbot_plugin_parser_x
```

环境需要：

1. AstrBot 所用 Python 环境及插件依赖；项目声明 Python `>=3.10`，并非所有最低版本组合均已实机验证。
2. `ffmpeg` 可由 AstrBot 进程从 `PATH` 调用。
3. Playwright `>=1.58,<2` 及其匹配的 Chromium 和 Linux 系统库。安装 Python 包不等于安装浏览器，插件不会自动安装浏览器和系统软件。

在 **AstrBot 实际运行的容器、Python 环境与用户**下安装浏览器：

```bash
python -m playwright install chromium
```

**Docker / 独立协议端：**通过本地路径发送媒体时，OneBot 端也必须能读取该路径。通常需要将插件数据目录共享到协议端的相同绝对路径；网络互通不等于文件互通。修改挂载或重建容器前请备份登录态和环境。

详细依赖、环境验证及目录共享见 [安装指南](docs/INSTALL.md)。pip/wheel 构建产物本身不替代 AstrBot 的插件安装注册。

## 使用与配置

直接发送支持平台的作品链接或含链接的分享文案。

- `/开启解析`：开启当前会话。
- `/关闭解析`：关闭当前会话。

两个命令对当前会话生效，无需管理员权限。

常用配置：

| 配置 | 说明 |
| --- | --- |
| `comments.enabled` | 统一卡片/评论开关；关闭后不生成或复用插件卡片，原始媒体不因此停止发送 |
| `comments.display_count` | 主评论数量，默认 10，范围 1–20；楼中楼不占主评论数量 |
| `behavior.reaction_enabled` | 解析成功后对原消息添加表情回应；关闭不影响解析 |
| `performance.video_codec` | `auto` / `hevc` / `avc`，默认 `hevc`；优先选择平台已提供的编码，无可用匹配时回退，不强制转码 |
| `behavior.disabled_sessions` | 已关闭解析的会话；群聊使用纯群号，对接入的机器人共同生效；私聊使用完整会话标识 |
| `cookies.*` | 各平台登录态，按需填写 |

默认启用评论过滤，包括纯提及/喊人、广告、二维码配图及重复评论；正常正文中的 `@用户` 保留，楼中楼独立过滤。过滤后数量可能少于设置值。

### Cookie 与账号风险

填写网页请求中的完整 Cookie：`key=value; key2=value2`。不要包含 `Cookie:` 前缀、JSON 或文件路径。建议使用专用账号，失效后手动更新。

| 字段 | 用途 |
| --- | --- |
| `cookies.bili_ck` | B站作品、动态、评论及可用清晰度；可留空匿名尝试 |
| `cookies.douyin_ck` | 抖音作品与热门评论；评论需要有效登录态 |
| `cookies.kuaishou_cookie` | 快手热门评论；可选，匿名或登录态均不保证通过风控 |
| `cookies.weibo_cookie` | 微博热门评论；公开作品可匿名尝试 |
| `cookies.xiaohongshu_cookie` | 小红书正文必要时回退与评论；正文优先匿名，评论需满足登录等条件 |
| `cookies.xiaoheihe_cookie` | 小黑盒帖子与热门评论；缺少时可能触发验证 |
| `cookies.acfun_cookie` | AcFun视频、下载与评论；可选 |
| `cookies.zhihu_cookie` | 知乎内容请求；可选，不向媒体域名传递 |
| `cookies.wechat_channels_cookie` | 可选元宝 Cookie，仅用于 `yuanbao.tencent.com` 的视频号解析辅助 |
| `cookies.netease_cookie` | 可选的本人网易云登录态；仅使用账号已有权限，不保证歌曲提供完整音频 |

**没有“不封号”保证。** 小红书等平台可能触发验证、限制或封禁。Cookie 无法绕过付费、地域、权限或验证码限制。配置、缓存及部分下载生成的 Cookie 文件可能含敏感信息，切勿公开分享。

## 调试与排障

从 AstrBot WebUI 插件详情打开 **解析调试台**，粘贴分享文本，查看解析、媒体和任务事件。调试使用当前配置与登录态，不代表支持其它消息适配器。

开启“只响应调试页面”后，QQ 分享不会触发解析；关闭并等待插件重载后恢复。调试任务最长 20 分钟，同时最多 4 个、每个登录用户最多 2 个；取消任务会清理相关转码/重封装子进程。

- **解析成功但发送失败：**先检查协议端读取权限、共享目录与路径大小写，再检查媒体格式、大小及协议端错误。单轨下载合格不保证协议端接受合并成品。
- **没有评论/卡片：**检查统一开关、登录态和调试结果；上游可能返回空评论、触发风控或被过滤。评论失败不应阻断原始媒体。
- **群里不解析但调试可用：**检查调试独占模式、会话关闭状态和链接是否属于主动跳过类型。
- **重复解析仍是旧评论：**相同输入及配置的完整结果、媒体和卡片可缓存 24 小时，命中时不重新请求。缓存位于 AstrBot 数据目录的 `plugin_data/astrbot_plugin_parser_x/`，每天 00:00 按 AstrBot 时区（未配置时 Asia/Shanghai）清理过期文件。
- **渲染是否联网：**截图使用本地 Chromium 与随包中文字体；作品、头像和平台表情素材仍可能需要下载，整个解析流程并非离线。酷安与小红书的在线静态图按需下载并缓存到 `cache_dir/emote_cache/`；小红书另恢复 v0.0.1 的 22 张旧版静态 PNG 首帧，以免 PAG 渲染不可用时丢失原有表情。没有可用来源的表情仍保留原名，不使用空白首帧。卡片评论的受管理表情预热最多处理 32 个不同 token，总等待预算 3 秒；超时或超出数量时仍保留可读表情名，不无限阻塞出图。其它评论配图不作为任意后台预热 URL。彩色 Emoji 回退效果依环境字体而异。
